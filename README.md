# 邑南町日貫地区 デジタルツイン試作（ビューア）

島根県から提供された航空レーザー測量データにもとづく地形と、土中水分センサの働きを見るための試作ビューアです。

- 公開ページ: https://motoki-design.github.io/hinui-digitaltwin/
- ブラウザで開くだけで動きます（外部ライブラリを同梱しているため、社内ネットワークやオフラインでも表示できます）
- 地形は10 mおきの格子（18.6万点）。標高は東京湾平均海面、座標は平面直角座標第III系
- 「粒」は水の見せ方であって流体計算ではありません。根拠になる数値は画面右下の管理断面です
